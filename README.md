# website-builder

A lightweight React app that demonstrates a modern website builder experience. It includes a component library, live preview canvas, inspector panel, and a generated structure view so users can see how a site can be assembled from reusable blocks.

## Features

- Add sections like hero, features, pricing, CTA, text, and footer
- Select a section and edit its content through an inspector
- Toggle between desktop, tablet, and mobile preview modes
- See the generated page structure as JSON
- Build a polished landing page without writing complex frontend code

## Tech stack

- React
- Vite
- CSS

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal, usually:

```text
http://localhost:3000
```

## Project goal

This project is a starting point for a website builder product. It is intentionally simple, but the architecture can expand into a full builder with drag-and-drop editing, custom styling, reusable templates, CMS integration, and deployment tools.
